# 🎉 Ahmedabad Event Hub

Ahmedabad Event Hub is a web-based event management platform that helps users discover, explore, and register for events happening across Ahmedabad. The platform provides a simple and responsive interface for browsing events, while administrators can efficiently manage event details.

---

## 🚀 Features

- 🔐 User Authentication (Login & Registration)
- 📅 Browse Upcoming Events
- 📍 Event Details (Date, Time, Venue, Description)
- 🔎 Search & Filter Events
- 📝 Event Registration
- 👤 User Dashboard
- 🛠️ Admin Dashboard
- ➕ Add, Edit & Delete Events
- 📱 Fully Responsive Design

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Anirudh110607/Ahmedabd-Event-Hub.git
```

### 2. Navigate to Project Folder

```bash
cd Ahmedabd-Event-Hub
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the project root.

Example:

```env
PORT=3000
MONGO_URI=your_mongodb_connection_string
SESSION_SECRET=your_secret_key
```

### 5. Start the Server

```bash
npm start
```

or

```bash
node app.js
```

The application will run at:

```
http://localhost:3000
```
